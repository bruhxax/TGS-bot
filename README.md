# TGS-bot

Telegram-бот и Mini App для продажи VPN-подписок через Remnawave. Проект целиком написан на Go; интерфейс встроен в бинарный файл и не требует отдельного Node.js-сервиса.

## Что уже есть

- `/start` с кнопками Mini App и одноразовым бесплатным периодом.
- Главная: срок подписки, устройства, трафик, продление и ссылка подключения.
- Тарифы, промокоды, ЮKassa и CryptoBot с проверяемыми webhook.
- Тикеты и чат с поддержкой внутри Mini App.
- Ноды Remnawave, HWID-устройства, платежи и реферальная ссылка.
- Админ-раздел: язык, аварийный режим, диагностика, функции, триал, интеграции, контент, темы, порядок разделов, тарифы, пользователи, тикеты, рефералы, рассылки и промокоды.
- Telegram Mini App HMAC-проверка, подписанные сессии, PostgreSQL и автоматические миграции.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните обязательные значения.
2. Убедитесь, что DNS `PUBLIC_HOST` указывает на сервер и порты 80/443 открыты.
3. Запустите:

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f app
```

После первого запуска откройте Mini App администратором и заполните раздел «Админ → Интеграции». Все изменяемые настройки, включая ключи платёжных систем и Remnawave, хранятся в PostgreSQL; `.env` нужен только для стартовых секретов и инфраструктуры.

## Remnawave

Поддерживается актуальный API v3: поиск пользователя по Telegram ID, создание и обновление пользователя, внутренние/внешний сквады, ноды, список и удаление HWID. Для совместимости поиск пользователя также имеет fallback для API v2.

В админке укажите URL панели без завершающего `/`, API Token и необязательный секрет webhook. Адрес webhook:

```text
https://<домен>/api/webhooks/remnawave
```

Если секрет заполнен, Remnawave должен передавать его в заголовке `X-Webhook-Secret`. Выдача триала или оплаченного тарифа считается успешной только после успешного ответа панели.

## Платежи

- ЮKassa: `https://<домен>/api/webhooks/yookassa`
- CryptoBot: `https://<домен>/api/webhooks/cryptobot`

ЮKassa webhook повторно проверяется запросом к ЮKassa. CryptoBot webhook проверяется по HMAC-подписи. Повторный webhook не выдаёт подписку второй раз.

## Рассылка

Отправьте боту команду `/broadcast`, текст сообщения и при необходимости кнопки отдельными строками:

```text
/broadcast Обновление сервиса

Открыть Mini App | https://example.com
```

Бот покажет предпросмотр и запросит подтверждение.

## Разработка

```bash
gofmt -w ./cmd ./internal
go test ./...
go vet ./...
```

Локальный дизайн можно открыть без Telegram по адресу `/app?preview=1`. Этот режим содержит только демонстрационные данные и не создаёт серверную сессию.
